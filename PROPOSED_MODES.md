# Proposed Custom Modes for the Musica Project

Based on the project analysis, here are 15 custom modes tailored for the Musica audio studio web application:

## 1. API Developer
Build and maintain API endpoints (REST, GraphQL, authentication, rate limiting).

## 2. Audio Engineer
Design audio processing features (file manipulation, format conversion, quality optimization).

## 3. Component Designer
Create reusable UI components (React/Vue/Angular, documentation, Storybook, accessibility).

## 4. Database Architect
Design and manage database schemas (data modeling, query optimization, migrations, security).

## 5. Performance Optimizer
Optimize application performance (profiling, bundle size reduction, memory management, caching).

## 6. Security Auditor
Audit and improve security (vulnerability identification, auth review, data validation, dependency checks).

## 7. Stripe Integration Specialist
Manage Stripe payment integration (API configuration, payment processing, webhooks, billing, tax compliance).

## 8. Testing Engineer
Write and maintain tests (unit, integration, end-to-end, test automation, CI/CD, performance testing).

## 9. Documentation Writer
Create and maintain documentation (API docs, component docs, user guides, code comments, architecture).

## 10. Deployment Specialist
Manage deployment and hosting (CI/CD pipelines, cloud deployment, environment management, monitoring).

## 11. Configuration Manager
Manage environment and configuration (env vars, config files, secret management, validation, dev/prod configs).

## 12. Audio Effects Designer
Design and implement audio effects (algorithms, real-time processing, filter design, visualization, enhancement).

## 13. Music Theory Expert
Implement music theory and generation (theory implementation, audio generation, chord progressions, melody composition, harmony analysis).

## 14. Analytics Specialist
Analyze and optimize user analytics (user behavior, performance metrics, A/B testing, data visualization, analytics pipeline).

## 15. Integration Specialist
Manage third-party integrations (API integration, OAuth, data synchronization, webhook management, error handling, integration testing).

Each mode includes:
- Role definition with expertise areas
- When to use the mode
- Tool group permissions (read, edit, command, mcp, browser)
- File patterns for edit access

To implement these modes, replace the contents of `.roomodes` with the full mode definitions.
